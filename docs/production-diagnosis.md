# 生产控制台诊断记录

## 2026-08-22

用户提供的控制台日志包含三类信息。第一类是托管平台向页面注入编辑器、分析和图标资源时，受 VeilRoom 严格 CSP 拦截产生的告警。第二类是应用旧版本中 Vue 在片段节点协调时出现的 `nextSibling`、`__vnode` 和 `textContent` 空引用。第三类是会话创建后 WebSocket 升级失败。

匿名会话创建 API 在已发布域名上已验证返回 `201` 和有效能力参数，说明创建端点本身可达。后续修复应以最新部署脚本版本为准，验证单根 Vue 容器是否消除了页面状态切换中的 DOM 协调异常，并独立确认代理后的 WebSocket 升级响应。平台注入脚本不是 VeilRoom 业务依赖，不应作为隐私产品功能的一部分放行。

单根容器版本已在发布域名加载，`#app` 仅包含一个 `.app-root` 子节点，创建按钮可切换至新会话地址，说明旧版 Vue 根片段协调问题已不再阻止点击流程。标准 WebSocket 握手在同一发布域名上收到 `403`；现有来源校验将 `Origin` 与反向代理传入的内部 `Host` 比较，因此需要改为使用受代理传递的公开主机名，同时保持严格的同源比较。
