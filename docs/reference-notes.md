# VeilRoom 参考设计观察

## Signal

Signal 的首页以一句直截了当的核心承诺作为视觉锚点，并在首屏后立刻用“Why use Signal?”承接价值解释。其价值语言聚焦隐私默认开启、无追踪与内容本身，而不是堆叠复杂的技术术语。VeilRoom 将借鉴这一“一个承诺、两组理由”的信息顺序，但采用更短暂、更私密的双人会话语境。

## Apple

Apple 的导航、卡片和行动入口具有清晰的材质层级：内容区保持大面积留白，首要行动明确，辅助信息弱化，动效不抢占阅读。VeilRoom 将只借鉴磨砂边界、克制过渡和单一高优先级行动，不复制其商业页面的结构或视觉素材。

## Telegram

Telegram 把能力表达拆为短而明确的单词组，并依赖易识别的图形与轻量状态反馈，避免在主流程中反复解释同一件事。VeilRoom 将用状态、图标、倒计时与小幅微动效来表达会话锁定、密钥确认和临近销毁，而不是在侧栏重复说明。

## Kimi

Kimi 的界面将大部分注意力留给单一工作区，交互控件轻量、边界克制，并以细微的动态提示表现系统活性。VeilRoom 将采用同样的内容优先原则：黑底、低对比度动态字节图层、紧凑玻璃材质操作控件与仅在需要时出现的状态反馈。

## Element Plus

Element Plus 的结构将导航、侧栏与主滚动区域明确分离；内容区在固定容器中滚动，控件层不会挤压主内容。VeilRoom 将用同样的容器规则解决会话界面被消息撑高和操作区被底部邀请抽屉遮挡的问题。

## Kimi Research

Kimi 的研究页通过极简标题、宽阔留白和网格卡片建立技术感，技术内容成为唯一主角。VeilRoom 的“为什么选择”和“安全性”区块将以短句、状态符号和结构化卡片表达事实，不使用夸张的营销叙述。

## Google Antigravity

Antigravity 以明确的主动作、粗粒度文字变形和动态符号营造技术氛围，但仍给主体文字足够的对比度与留白。VeilRoom 将把动态限制在背景字节码和标识悬浮态，避免让视觉噪声进入聊天、计时与安全状态等高优先级内容。

## Vercel

Vercel 以黑白高对比、严格网格和少量高权重行动保持专业感。VeilRoom 将采用黑色基底、细边界和单一霓虹强调色；强调色只服务于创建、发送和安全确认等明确动作，避免装饰性滥用。
